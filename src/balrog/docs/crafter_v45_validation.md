# Crafter V45 qualified reference evidence

The frozen V45 research controller achieved all 22 native achievements in **40/40 native episodes**, then earned **1.0 in 10/10 fresh Harbor trials** using the separate verifier. Regrading the ten exported artifacts after the original containers were removed produced **1.0 in 10/10 regrades**. The original 2,000-action budget and native achievement score were retained.

These are results for a **privileged schema-3 research reference**, not an ordinary text-only agent or the canonical `oracle` task solution. They do not promote the archived 239/255 baseline, alter production fixtures, establish model parity, or imply maintainer approval. The machine-readable counts, source bindings and per-trial hashes are in [crafter_v45_validation.json](crafter_v45_validation.json).

## Access boundary and remaining acceptance

The reference runs as UID 1001 in the game service, reads private game snapshots and uses a detached native planning model. Actions still enter the ordinary logged game-action interface. The saved installation records report unchanged native runtime bindings, a 2,000-action limit and normal-agent isolation before and after execution: private paths and result credentials were absent, and four private HTTP route probes returned 404. The independent saved-artifact audit checked the installed policy hash, public action equality, original initial-observation hashes, protected artifact source, stopped-container timestamps and cleanup/log hashes for all ten trials.

Maintainer acceptance is still needed for this privileged reference interface and for using the protected live native score when replay diverges. This does not demonstrate ordinary-agent performance, Daytona execution or paid model parity. No controller has been installed into canonical task solutions, and the official Crafter reference fixtures remain unchanged.

The full controllers, raw native reports and Harbor job directories remain local and are **not published in this summary**. The committed JSON preserves their identifying hashes and compact outcomes, not a standalone reproduction package. Earlier controller revisions and failures remain separate; these measurements should not be pooled into a claim about all development attempts. The 40 native episodes also did not exercise every V45-specific branch, so full-score results do not establish the contribution of each individual change.
